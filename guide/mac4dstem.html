mac4DSTEM

mac4DSTEM is a native Mac app for 4D-STEM data: a diffraction pattern at every scan position. You change detectors and settings and see the result update right away.

It needs macOS 27 or later on Apple Silicon. Download and release notes are on GitHub.

Rooms

Rooms follow the data. Switch with ⌘1 to ⌘7.

RoomWhat it is for
PrepareOpen a file, check the calibration, crop, stride or clean hot pixels before you work.
ImagingReal and diffraction space side by side. Place bright-field, dark-field and annular detectors and watch the image change.
Bragg DisksFind the diffraction spots in every pattern and check them on screen.
Crystal MapsStrain and crystal orientation maps from the found spots.
ReconstructionPhase and field images (DPC, iDPC, parallax, ptychography).
ResultsCollect and export what you made.
SpectroscopyEDX spectrum images: element ID, maps, quantification.

Workflows

Make a virtual image

  1. Open your file (⌘O); check the scale in Prepare.
  2. Go to Imaging.
  3. Pick a detector type (bright field, annular dark field, point) and drag it over the pattern.
  4. Read the real-space image beside it; it updates as you move the detector.
  5. Export from Results.

Map strain

  1. Open the file and go to Bragg Disks.
  2. Run disk detection; adjust the threshold until the markers sit on the spots.
  3. Go to Crystal Maps and choose strain.
  4. Read the strain maps; the quality and indexed-fraction numbers show where to trust them.
  5. Export the maps from Results.

Map crystal orientation

  1. Find the Bragg disks first.
  2. In Crystal Maps choose orientation and load a structure (a CIF file or a Materials Project id).
  3. Run the match.
  4. Read the orientation map and its reliability map; low reliability marks places to doubt.

Map phase and fields

  1. Open the file and set the detector geometry in Imaging.
  2. Go to Reconstruction and choose DPC, iDPC or ptychography.
  3. Run it and read the image. Phase and precipitate mapping are marked unvalidated in the app.

Look at EDX

  1. Open an EDX spectrum image.
  2. Go to Spectroscopy; run Auto ID to find the elements.
  3. Draw a region to see its spectrum.
  4. Quantify and read the composition.

Results are marked on screen when they are not yet validated. Full details: README and status on GitHub.
