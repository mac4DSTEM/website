mac4DSTEM documentation

How to install mac4DSTEM, open your 4D-STEM data and work through an analysis, one step at a time. The tutorials use the demo dataset that is built into the app, so you can follow along without data of your own.

Tutorials

Each tutorial takes about ten minutes. They build on each other in this order.

  • 1. Virtual imagingBright-field and dark-field images from any detector you draw, and diffraction from any region of the scan.
  • 2. CalibrationOrigin, elliptical distortion, rotation and pixel sizes, and how to tell when a dataset is quantitative.
  • 3. Bragg disksFind the disks in every pattern and judge how well the detection worked.

Tutorials on strain and crystal maps, EDS spectroscopy and precipitate analysis follow.

About these pages

These pages describe mac4DSTEM {version}. Names of buttons and settings are written as the app shows them, like Detect All Disks. The methods come from py4DSTEM and are checked against it; how the numbers are checked is on the front page.
