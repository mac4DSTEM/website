Open your data

Which files mac4DSTEM reads, how to open a dataset that is larger than your Mac's memory, how the window is laid out and where your work is saved.

EDS spectrum images open in the Spectroscopy workspace, on their own or together with the 4D scan.

Three ways to open

  • Choose File › Open Dataset… (⌘O), or the button of the same name in the welcome window.
  • Drag a file onto the window.
  • Pick it from File › Open Recent.

Each dataset opens in its own window. File › New Dataset Window (⌘N) gives you a second one.

Large datasets

Open with Options… shows a preview before anything is loaded and lets you make the dataset smaller. The source file is never changed.

  • Crop the scan to the region you care about.
  • Crop the detector. This limits the angular range.
  • Bin the detector. This keeps the angular range but makes disk positions coarser. Counts per pixel grow with the bin factor squared, so recheck any absolute threshold afterwards.
  • Keep in memory, or turn it off to let the analyses read from disk in bounded pieces. The sheet shows the size of your selection against the memory of your Mac and warns when it takes more than half.

To make a smaller file once and keep it, use Preprocess Raw Data…. It writes a cropped, binned and hot-pixel-filtered copy as a py4DSTEM datacube and leaves the original alone.

The window

  • Sidebar, left. Seven workspaces in the order the data flows: Prepare, Imaging, Bragg Disks, Crystal Maps, Reconstruction, Spectroscopy and Results. ⌘1 to ⌘7 switch between them.
  • Panes, centre. The diffraction pattern and the real-space image, side by side.
  • Inspector, right. The settings of the workspace you are in. Changes show in the panes while you make them.
  • Toolbar. One main action per workspace, such as Detect All Disks. Work over the whole scan starts only when you press it, shows its progress and can be cancelled.
  • Output and Lineage, bottom. Output is the log of what ran. Lineage shows every step that led to a result.

Switching workspaces never starts a computation and never discards one.

Sessions: where your work is saved

mac4DSTEM saves calibration and results in a session file beside the dataset, named after it and ending in .mac4dstem.h5. Your dataset itself is never written to.

  • Dataset › Save Calibration to Session Sidecar saves the calibration.
  • Dataset › Save Current Result to Session Sidecar saves the result on screen.
  • When you open the dataset again, the session is found and restored.

macOS only lets an app read the files you picked. If the session file is not picked up, choose Dataset › Allow Access to Session Sidecar… once and select it.

Export

  • File › Export Result PNG… and Export Diffraction PNG… save what the panes show.
  • The Results workspace exports figures and data. Bragg vectors, datacubes and maps are written as EMD files that py4DSTEM reads.
  • Every export records the method the result came from and its calibration.
