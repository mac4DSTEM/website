Troubleshooting

Common problems and what to do about them. If yours is not here, write to me or open an issue.

Installing and opening the app

The app does not open

mac4DSTEM needs macOS 26 or later on an Apple silicon Mac. On macOS 14 to 25, use version 3.0.0.

Opening data

My file does not open, or opens as the wrong dataset

Check that the format is in the list of formats. The Merlin and EMPAD readers are preview-grade. If a file in a listed format fails, please report it with the format, the scan and detector size and the program that wrote it. A small example file helps most.

A Merlin or EMPAD file opens without its settings

Keep the companion file (.hdr for Merlin, .xml for EMPAD) in the same folder as the data. If the app asks for access to it, allow it.

The dataset is larger than my Mac's memory

Use Open with Options… to crop or bin before loading, or turn off Keep in memory so the analyses read from disk. See Large datasets.

My saved session did not come back

The session file must sit beside the dataset and keep its name. If it is there and is not picked up, choose Dataset › Allow Access to Session Sidecar… and select it.

A workspace in the sidebar is greyed out

Spectroscopy needs an EDS spectrum image. The other workspaces except Results need a 4D scan. A window that holds only a spectrum image offers Spectroscopy and Results.

Imaging and calibration

The BF, ADF and HAADF presets do not fit my pattern

The presets are fractions of the detector until the beam has been measured. Run Calibrate Origin in Prepare, then apply the preset again.

The scale bar is in pixels

The file carries no scan step size, and it cannot be measured from the data. Enter the R pixel size in Prepare from your acquisition settings.

A result is marked "not quantitative"

A calibration step it depends on is missing or failed its check. The readiness list in Prepare shows which one; rest the pointer on a row to read what it unlocks. See the calibration tutorial.

Fit Ellipse is refused

The fit needs a ring with signal all the way round. Spots from a few grains fit an ellipse as well as a distorted detector does, so the app refuses instead of giving a wrong correction. Move the annulus onto a ring from an amorphous or polycrystalline area, or leave the ellipse unset.

Bragg disks

No disks are found

Build a probe kernel first (Build Kernel). Then check that its probe radius matches the disks in your pattern, and lower Minimum relative and Minimum absolute under Advanced detection.

Too many false disks

Raise Minimum relative, raise Minimum spacing to about the distance between neighbouring disks, and add a little Correlation smoothing σ. The Bragg disks tutorial shows how to read the acceptance funnel.

"Detection settings changed — rerun Detect All Disks"

You changed a detection setting after the last full run. Strain and orientation maps use the disks of the last full run, so press Detect All Disks again before computing them.

Reporting a problem

Please include the mac4DSTEM version, the file format, the scan and detector size and what you expected to see. A difference from py4DSTEM with the numbers attached is the most useful report of all. Open an issue on GitHub or write to mail@mac4dstem.com.
